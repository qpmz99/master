# 天气查询应用

这是一个简单的天气查询网页应用，它允许用户输入城市名称，然后从和风天气 API 获取并显示该城市的当前天气信息。

## 功能

- 根据用户输入的城市名称查询实时天气。
- 显示温度、湿度、风速和天气状况。
- 基本的错误处理，例如城市未找到或 API 请求问题。

## 如何运行

1.  **获取和风天气 API 密钥：**
    *   访问 [和风天气开发服务](https://dev.qweather.com/) 并注册一个账户。
    *   登录后，在控制台中创建一个新的项目，选择免费订阅（或您选择的套餐）。
    *   在项目详情中，您将找到您的 API Key。复制此密钥。

2.  **配置 API 密钥：**
    *   打开 `script.js` 文件。
    *   找到以下行：
        ```javascript
        const apiKey = 'YOUR_HEFENG_WEATHER_API_KEY';
        ```
    *   将 `'YOUR_HEFENG_WEATHER_API_KEY'` 替换为您在步骤1中获取到的实际 API 密钥。

3.  **打开应用：**
    *   在您的网页浏览器中直接打开 `index.html` 文件即可。

## 文件结构

-   `index.html`: 应用的主要 HTML 结构。
-   `style.css`: 应用的 CSS 样式表。
-   `script.js`: 包含与和风天气 API 交互以及更新页面的 JavaScript 逻辑。
-   `README.md`: 本说明文件。

## 注意事项

-   此应用依赖于和风天气 API。如果 API 服务中断或您的 API 密钥无效/过期/超出配额，应用可能无法正常工作。
-   和风天气的免费套餐有请求次数限制，请注意使用。
